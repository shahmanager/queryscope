## Method

- **Decision accuracy** — correct answer, correct refusal, or correct clarification request.
- **Execution accuracy** — result-set equality with independent gold SQL, order-insensitive, floats rounded to 2 decimals. Denominator: answerable questions only.
- **Intent accuracy** — retrieved family matches the family expected by the question category.
- **Refusal precision** — correct refusals / all refusals, across every category. A wrongly refused in-scope question is a false positive.
- **False-refusal rate** — in-scope questions wrongly refused / all in-scope questions.
- **Coverage** — questions where a validated plan was produced.
- **Estimated scan cost** — `EXPLAIN QUERY PLAN` heuristic: 100 per SCAN, 10 per SEARCH, 50 per TEMP node. A comparative signal, not a timing.
- **Clock** — pinned to 2026-06-30 so relative dates never drift.

## What this does not measure

Open-domain language understanding, arbitrary schemas, write workloads, or concurrency. The benchmark is in-domain by design; see the README trade-offs.
